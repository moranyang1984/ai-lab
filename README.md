# AI 小实验室（网页版）

《人工智能通识课（小学高年级）》15 讲的配套体验平台。纯静态网页，不需要服务器；AI 用 DeepSeek，也可以完全离线上课。

## 一、部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `ai-lab`），选 Public。
2. 把这个文件夹里的**全部文件**上传到仓库根目录（包括 `.nojekyll`、`img/`、`relay/`）。
   - 网页上传：仓库页面 → Add file → Upload files，把文件和文件夹一起拖进去 → Commit。
   - 或命令行：`git init && git add -A && git commit -m "AI 小实验室" && git branch -M main && git remote add origin https://github.com/你的用户名/ai-lab.git && git push -u origin main`
3. 仓库 → Settings → Pages → Source 选 “Deploy from a branch”，Branch 选 `main`、目录选 `/ (root)` → Save。
4. 等一两分钟，网址是 `https://你的用户名.github.io/ai-lab/`。

以后更新平台，只要把改过的文件再提交一次。

## 二、接上 DeepSeek

不配置也能用：打开就是“离线演示”，15 讲都能完整上课。

### 方式 A：在浏览器里填密钥（最简单，适合教师机演示）

1. 到 platform.deepseek.com 申请 API 密钥并充值。
2. 打开网页，点左下角的「离线演示」按钮 → 选「DeepSeek 大模型」→ 展开 DeepSeek，填密钥 → 点「测试」→「保存」。
3. 其他设备：在设置里点「复制配置链接」，在那台设备的浏览器里打开一次。

密钥只保存在那台设备的浏览器里，不会上传到 GitHub。但配置链接里带着密钥，拿到链接的人就能用你的额度，只发给本班设备。

### 方式 B：中转服务（适合全班学生机长期使用）

见 `relay/README.md`。真正的密钥放在中转服务里，网页只带一个班级口令，所有设备打开即用。

### 不要做的事

不要把 `sk-` 开头的真密钥写进 `ai-config.js` 或仓库里的任何文件。仓库和网页都是公开的，密钥会被扫描盗用。

## 三、和 claude.ai 上的版本有什么不同

| 项目 | 网页版（GitHub） | 说明 |
| --- | --- | --- |
| 文字类体验（写诗、整理资料、审稿、出题、解题、翻译、写网页和小游戏、推理） | DeepSeek | 结果标“来源：DeepSeek 大模型” |
| 作画、图生视频、科学动画 | DeepSeek | 由模型写 SVG 代码画出来 |
| 看图类体验（第 1 讲识图和找物体、第 6 讲拍照翻译） | 离线演示 | DeepSeek 默认模型不能看图；如果你的账户有看图模型，在设置的「看图模型」里填模型名 |
| 语音（第 4、5 讲） | 浏览器自带的语音识别和朗读 | 与 AI 模式无关；需要 https 和麦克风授权 |
| 学情数据 | 只存在每台设备的浏览器里 | 没有云端同步。学生在「我的能力图谱」里导出记录文件，教师在「学情分析」里导入 |
| 连不上 AI、余额不足、密钥错误 | 自动改用离线演示 | 页面会提示原因 |

## 四、文件说明

- `index.html`、`app.js`、`nav.js`、`report.js`、`l1.js`…`l15.js`：平台本体。
- `ai.js`：AI 模式和各种 AI 任务。
- `webdesk.js`：网页版的大模型接入（浏览器直接调用兼容 OpenAI 的接口）。
- `ai-config.js`：部署者可改的默认配置（默认模式、模型名、中转地址）。
- `relay/`：可选的中转服务代码和说明。
- `.nojekyll`：告诉 GitHub Pages 原样发布文件，不要删。

## 五、已知情况

- 浏览器直连 `api.deepseek.com` 需要 DeepSeek 允许网页跨域访问。如果设置里点「测试」显示“连不上”，而密钥和网络都没问题，就改用方式 B。
- `github.io` 在中国大陆部分学校网络里不稳定。同一套文件可以原样放到任何静态托管或学校自己的服务器上。
- 页面字体来自 Google Fonts，加载不到时自动用系统字体，不影响使用。
- 学生输入的文字（提示词、初稿等）会发送给 DeepSeek。平台不要求也不发送姓名、照片和录音；请提醒学生不要在输入框里写个人信息。
- 模型名以 DeepSeek 文档为准（2026-11 核对时为 `deepseek-flash`）；改名后在设置里或 `ai-config.js` 里改。
